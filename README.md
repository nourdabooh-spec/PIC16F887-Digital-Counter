# PIC16F887 Digital Counter

## Project Overview
A digital counter using PIC16F887 microcontroller.

## Features
- Counts from 00 to 25.
- Start, Pause, and Reset buttons.
- Two-digit 7-Segment Display.
- LCD status display.
- Running LED indicator.

## Tools Used
- MikroC PRO for PIC
- Proteus 8.9
- PIC16F887
- C Programming

## Project Functionality
The counter automatically counts from 00 to 25 and then restarts from 00. Users can control the counter using Start, Pause, and Reset buttons.
